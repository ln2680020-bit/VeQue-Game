# Về Quê — Pixel Art Farming Adventure

A countryside life-simulation game project built with HTML, CSS, and JavaScript.

## Current direction
- Main visual direction: Super Retro Ranch-inspired 16×16 Pixel Art.
- Keep the existing playable prototype while upgrading it incrementally.
- Core systems: movement, farming, watering, harvesting, selling crops, day/night, and local save data.
- Planned systems: larger world areas, NPCs, quests, crafting, animals, professions, exploration, and an online marketplace.

## Development notes
- Preserve working gameplay while making small, testable changes.
- Keep the original prototype backed up before major refactors.
- Test the game in a desktop browser after each change.
